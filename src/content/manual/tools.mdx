Tools are plug-ins that do a job around a project rather than processing
audio in place. Audacity 4 ships four of them, all written in Nyquist.

## Where to find them

The **Tools** menu, below the macro commands.

## What is in it

- [Nyquist plugin installer](/manual/tools/nyquist-plugin-installer)
  — install additional Nyquist plug-ins from files on disk.
- [Regular interval labels](/manual/tools/regular-interval-labels)
  — create a label track with labels at even intervals.
- [Sample data export](/manual/tools/sample-data-export)
  — write sample values out to a text, CSV or HTML file.
- [Sample data import](/manual/tools/sample-data-import)
  — read sample values from a text file into a new track.
