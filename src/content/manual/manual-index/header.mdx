The Header is Audacity's menu bar. Every command in the application is
reachable from it, including the ones that also have toolbar buttons or
keyboard shortcuts. On macOS it sits in the system menu bar; on Windows and
Linux it runs along the top of the Audacity window.

There are eleven menus, in this order.

## The menus

- [File](/manual/manual-index/header/file) — creating, opening, importing,
  saving, exporting, sharing and closing projects.
- [Edit](/manual/manual-index/header/edit) — undo and redo, the clipboard
  commands, and the commands that change audio already in the project.
- [Select](/manual/manual-index/header/select) — choosing what the next
  command will act on, plus looping and zero-crossing tools.
- [View](/manual/manual-index/header/view) — zoom, panels, workspaces and
  waveform display options.
- [Record](/manual/manual-index/header/record) — starting a recording, on
  the current track or a new one.
- [Tracks](/manual/manual-index/header/tracks) — creating, duplicating,
  removing and mixing down tracks.
- [Generate](/manual/manual-index/header/generate) — creating new audio such
  as tones, noise and silence.
- [Effect](/manual/manual-index/header/effect) — processing selected audio,
  and managing effect plugins.
- [Analyze](/manual/manual-index/header/analyze) — inspecting audio without
  changing it.
- [Tools](/manual/manual-index/header/tools) — utilities such as raw data
  import and resetting the configuration.
- [Help](/manual/manual-index/header/help) — learning resources, updates,
  account linking and recovery commands.

## Notes

- Many items are greyed out until they make sense — most need a project to
  be open, and several need a selection or some audio in the project.
- Menu items that carry a keyboard shortcut show it beside their name.
  Shortcuts can be changed on the
  [Shortcuts](/manual/manual-index/preferences/shortcuts) preferences page.
