# Tools toolbar

The [three toolbars](/manual/manual-index/toolbars) split the window between
them; this one is where the work happens — playback and recording, the
editing tools, zoom, the playhead position, snapping and the record level.
It is also the only toolbar you can move.

## Moving the Tools toolbar

Grab the Transport Toolbar's drag handle and drag it:

- Drop it near the top of the window to dock it at the top.
- Drop it near the bottom of the window to dock it at the bottom.
- Drop it anywhere else to leave it floating at that position.

The Project Toolbar and Selection Toolbar stay fixed in place.

## Navigating toolbars with the keyboard

Once a toolbar has focus, arrow keys move between its buttons and controls. See Accessibility and Keyboard Navigation for the full keyboard navigation model, including an alternative mode for screen reader users.

## The controls, by group

- [Transport](/manual/manual-index/toolbar/transport) — Play, stop, record, the skips and the loop toggle.
- [Tools](/manual/manual-index/toolbar/tools) — The editing tools — toggles that change what clicking does, and buttons that act on the selection.
- [Zoom tools](/manual/manual-index/toolbar/zoom-tools) — Getting closer to the waveform and back out again.
- [Selection](/manual/manual-index/toolbar/selection) — The playhead position, as a number you can read and edit.
- [Music](/manual/manual-index/toolbar/music) — Tempo and time signature, shown in the Music workspace.
- [Snapping](/manual/manual-index/toolbar/snapping) — Snap edits, clips and selections to a grid.
- [Metering](/manual/manual-index/toolbar/metering) — The record and playback level meters.
