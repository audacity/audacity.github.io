Controls whether the view follows the playhead while audio is playing or
recording. With it on, the view scrolls as the playhead advances so the
playhead stays in sight; with it off, the view stays exactly where you left
it and the playhead simply runs off the edge.

It is on by default.

## Where to find it

Right-click the timeline ruler and choose **Update display while playing**.
The item is checked while following is on.

## Notes

- If you scroll by hand during playback, following pauses for a few seconds
  so your scroll is not immediately undone, then resumes.
- [Pinned playhead](/manual/manual-index/timeline/pinned-playhead) decides
  *how* the view follows. It has no effect while this option is off.
