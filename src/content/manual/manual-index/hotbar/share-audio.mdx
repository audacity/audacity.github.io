Renders the project to an audio file and uploads it to audio.com, so you can
send someone a link instead of a file. Your project itself is not changed and
nothing is written to your computer.

## Where to find it

**Hotbar → Share audio**, or **File → Share audio**.

## How it works

1. Audacity asks for a **Track title** for the upload.
2. It exports the project in the format audio.com prefers and uploads it.
   Progress is shown in a notification while this happens.
3. When the upload finishes, the notification offers **View on audio.com**,
   which opens the shared audio in your web browser.

## Notes

- Greyed out until the project contains some audio, and unavailable while
  recording.
- Only present in builds where cloud support is enabled.
- Uploading needs an internet connection.
