Home is the screen Audacity shows when no project is open, and the one the
**Home** tab returns you to at any time. It is a project browser: nothing on
it edits audio.

## What is on the screen

Down the left is a narrow menu:

- **Cloud account** — your audio.com account. Only shown when cloud support
  is enabled.
- **Project** — the projects browser, which is what Home opens on.
- **Learn** — **not yet enabled in the current Audacity 4 alpha.**

The rest of the screen is the projects browser:

- A **search** field that filters the list as you type.
- Tabs for [New & recent](/manual/manual-index/project-management-menu/home/new-and-recent)
  and, when cloud support is enabled,
  [Cloud projects and Cloud audio files](/manual/manual-index/project-management-menu/home/cloud-projects-and-audio-files).
- A **Grid view** / **List view** pair of buttons, and — on the cloud tabs —
  a **Refresh** button.
- **New** and **Open other…** buttons along the bottom.

## Notes

- When the window is narrow the left-hand menu collapses to icons.
- The tab and the view type you last used are remembered.
