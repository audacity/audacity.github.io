Analyses the selected audio and plots how much energy it contains at each
frequency — a snapshot of the selection's tonal content, useful for spotting
hum, resonances or how bright or dark a recording is overall.

## Where to find it

**Analyze** menu.

## Notes

In the current Audacity 4 alpha the menu item is present but the spectrum
window itself has not yet been implemented.
