Exporting renders the project into a finished file that other applications
can play. It is a copy: the project itself, with its separate tracks, clips
and effects, is left exactly as it was.

## What you can export

- **Audio** — the whole project mixed down to a single file. This is the
  usual export. See
  [Export audio](/manual/manual-index/header/file#export-audio).
- **Labels** — the contents of a label track as a text file, under
  **File → Export other**. See
  [Export labels](/manual/manual-index/track-control-panel/label-track-item#export-labels).
- **MIDI** — present in **File → Export other**, but not yet enabled in the
  current Audacity 4 alpha.

## Exporting versus saving

Saving preserves the project so you can carry on editing it; exporting
produces a flat audio file that cannot be taken back apart. Most work needs
both — save the project to keep working, export when you need something to
send or publish. See [Save](/manual/manual-index/header/file#save).

## Notes

Exporting mixes the tracks together as playback would, applying each track's
volume, pan and effects. To share a project without exporting by hand, see
[Share audio](/manual/manual-index/hotbar#share-audio).
