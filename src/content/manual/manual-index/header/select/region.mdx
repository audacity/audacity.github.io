The **Region** submenu builds a time selection from reference points you
already have: the playback position, the start of the track's audio, or its
end. Instead of dragging a selection by hand, you pick the region you mean
and Audacity sets the selection's start and end for you.

The pages below cover each command in the submenu.

## Where to find it

**Select → Region**.
