The **Looping** submenu manages the loop region — the stretch of the
timeline that playback repeats while looping is on.

| Command | What it does | Shortcut |
|---|---|---|
| Toggle loop region | Turns looping on or off. Turning it off leaves the region defined but inactive. | <Shortcut client:load keys="l" /> |
| Clear loop region | Removes the loop region entirely. | <Shortcut client:load keys="shift+alt+l" /> |
| Set loop region to selection | Sets the loop region to the current time selection. With no time selection, it uses the extent of the selected clips instead; with nothing selected at all, the loop region is cleared. | <Shortcut client:load keys="shift+l" /> |
| Set loop region in/out | Opens a **Set looping region in/out** dialog where you type the start and end times directly. | <Shortcut client:load keys="i" /> |

## Where to find it

**Select → Looping**. The loop toggle is also a button in the transport
group of the toolbar — see
[Toggle loop region](/manual/manual-index/toolbar/toggle-loop-region).
