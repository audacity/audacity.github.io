Selects every track in the project. Unlike [Select all](/manual/manual-index/header/select/select-all),
which selects a time range across all audio, this selects the tracks
themselves — useful for track-level operations.

## Where to find it

**Select → Select all tracks**, or press <Shortcut client:load keys="cmd+shift+k" />.
