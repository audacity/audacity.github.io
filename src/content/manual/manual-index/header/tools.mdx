The **Tools** menu collects utilities that don't fit the generate, effect or
analyze categories — batch processing with macros, data import helpers, and
housekeeping commands.

## What it contains

- [Plugin manager](/manual/manual-index/header/effect/plugin-manager) —
  enable and disable the plugins that provide tools.
- [Manage macros](/manual/manual-index/header/tools/manage-macros) — create
  and edit macros.
- [Macros](/manual/manual-index/header/tools/macros) — apply an existing
  macro (not yet enabled in the current alpha).
- Below a separator, the list of available tools. This list is populated from
  your installed plugins, so its exact contents depend on what is installed
  on your machine — the built-in Nyquist set includes Nyquist plugin
  installer, Regular interval labels, and Sample data import and export.
  Installed extensions are listed here too.
- [Raw data import](/manual/manual-index/header/tools/raw-data-import) —
  import headerless audio data.
- [Reset configuration](/manual/manual-index/header/tools/reset-configuration) —
  return the application configuration to its defaults.
