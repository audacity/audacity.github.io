Labels are text markers that annotate a point or a stretch of your project —
song boundaries, edit notes, chapter marks. The Label submenu gathers the
commands for working with them: adding a label at the current selection,
renaming a label, pasting text into a new label, and opening the label
editor to manage every label in the project from one place.
