Removes the selected audio and moves everything after it on the same track
to the left, so no gap is left behind — often called a ripple delete. Each
track is closed up independently, which is what "per track" means.

## Where to find it

**Edit → Delete and close gap (per track)**, or press
<Shortcut client:load keys="shift+del" /> or
<Shortcut client:load keys="shift+backspace" />.

## Notes

It works on a time selection, on selected clips, or on selected labels —
the same targets as [Delete](/manual/manual-index/header/edit/delete), which
removes the same audio but leaves the gap open. If nothing is selected,
Audacity asks you to select the audio to delete first.
