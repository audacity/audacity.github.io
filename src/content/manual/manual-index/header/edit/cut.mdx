Removes the selected audio and puts it on the clipboard, ready to paste
elsewhere. The same command is available as a toolbar button in the Classic
workspace — see [Cut](/manual/manual-index/toolbar/cut).

## Where to find it

**Edit → Cut**, or press <Shortcut client:load keys="cmd+x" />.
