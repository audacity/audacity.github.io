Inserts whatever is on the clipboard at the edit cursor. The same command is
available as a toolbar button in the Classic workspace — see
[Paste](/manual/manual-index/toolbar/paste).

## Where to find it

**Edit → Paste**, or press <Shortcut client:load keys="cmd+v" />.
