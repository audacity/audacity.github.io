Replaces the selected audio with silence, leaving the clip the same length.
Because nothing moves, everything after the selection stays exactly where it
is — useful for removing a cough or a click without shifting the timing of
what follows.

## Where to find it

**Edit → Silence audio**, or press <Shortcut client:load keys="cmd+l" />.
The same operation is available as the
[Silence](/manual/manual-index/toolbar/silence) toolbar button.

## Notes

With a time selection, the selected range of each selected track is
silenced; with clips selected instead, the whole of each selected clip is
silenced. The command is disabled when the selected audio is already silent.
