Merges clips into a single clip — the opposite of
[Split](/manual/manual-index/header/edit/clip/split).

## Where to find it

**Edit → Clip → Join selected clips**, or press
<Shortcut client:load keys="cmd+j" />.

## Notes

With a time selection, the clips inside the selected range are merged on
each selected track. With clips selected instead, at least two clips must be
selected, all on the same track, sitting next to each other with no
unselected clip between them — otherwise the command is disabled.
