Opens the selected clip's name for editing, directly on the clip header.
Type the new name and confirm to apply it.

## Where to find it

**Edit → Clip → Rename clip**, or press <Shortcut client:load keys="f2" />.

## Notes

The command needs exactly one item selected — it is disabled when nothing,
or more than one clip, is selected. The same shortcut renames a selected
label; see [Rename Label](/manual/manual-index/header/edit/label/rename-label).
