Adds a label at the current selection — marking the selected stretch of
time, or the cursor position if nothing is selected — and immediately opens
it for naming, so you can type the label text straight away.

## Where to find it

**Edit → Label → Add label**, or press <Shortcut client:load keys="cmd+b" />.

## Notes

Labels live on a label track. To edit all of a project's labels in one
place, use
[Manage Labels](/manual/manual-index/header/edit/label/manage-labels).
