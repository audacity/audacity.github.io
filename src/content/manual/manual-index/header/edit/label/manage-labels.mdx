Opens the label editor, where every label in the project is listed in one
place for reviewing and editing — easier than hunting each label down on its
label track.

## Where to find it

**Edit → Label → Manage labels**. The same editor opens from the View menu
as [Show Label Editor](/manual/manual-index/header/view/show-label-editor).
