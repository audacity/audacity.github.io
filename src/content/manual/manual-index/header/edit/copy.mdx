Puts the selected audio on the clipboard without removing it. The same
command is available as a toolbar button in the Classic workspace — see
[Copy](/manual/manual-index/toolbar/copy).

## Where to find it

**Edit → Copy**, or press <Shortcut client:load keys="cmd+c" />.
