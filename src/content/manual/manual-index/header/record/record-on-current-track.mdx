Starts recording from the playhead position into an existing audio track. If
one or more tracks are selected, the recording goes into those; with nothing
selected, Audacity picks an existing track that matches the project's sample
rate. Choosing the command again while recording stops the take.

## Where to find it

**Record → Record on current track**. This is the same action as the
[Record button](/manual/manual-index/toolbar/record) in the toolbar, so
<Shortcut client:load keys="r" /> starts and stops it too.

## Notes

- If recording is paused, choosing the command resumes it.
- All selected tracks must share the same sample rate — recording won't start
  into a mixed-rate selection.
- Recording in Audacity 4 is non-destructive: the take lands as a new clip on
  the track rather than overwriting the audio already there.
