**Not yet enabled in the current Audacity 4 alpha.**

Opens the macro editor, where you create and edit macros — named sequences
of commands and effects that can be applied to a project or a batch of files
in a single step.

## Where to find it

**Tools → Manage macros**.

## Notes

Applying an existing macro is done from the
[Macros](/manual/manual-index/header/tools/macros) submenu next to this
command.
