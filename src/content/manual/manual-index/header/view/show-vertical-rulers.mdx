Toggles the vertical rulers — the per-track scale along each track's edge
that shows amplitude values for the waveform. See
[Vertical Rulers](/manual/manual-index/vertical-rulers) for more on the
rulers themselves.

The setting applies to the whole application, not per project.

## Where to find it

**View → Show vertical rulers**. The menu item is checked while the rulers
are shown.
