Zooms the timeline in, doubling the zoom level so a shorter stretch of the
project is shown in more detail. The same command is a toolbar button — see
[Zoom In](/manual/manual-index/toolbar/zoom-in).

## Where to find it

**View → Zoom → Zoom in**, or press <Shortcut client:load keys="cmd+=" />.
