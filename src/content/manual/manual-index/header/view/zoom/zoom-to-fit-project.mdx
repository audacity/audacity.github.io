Zooms so the whole project fits in the visible timeline, from the start to
the end of the last clip. The same command is a toolbar button, labelled
**Fit project** there — see
[Zoom to Fit Project](/manual/manual-index/toolbar/zoom-to-fit-project).

## Where to find it

**View → Zoom → Zoom to fit project**, or press
<Shortcut client:load keys="cmd+f" />.
