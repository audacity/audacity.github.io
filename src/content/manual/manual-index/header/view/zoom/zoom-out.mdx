Zooms the timeline out, halving the zoom level so a longer stretch of the
project fits on screen. The same command is a toolbar button — see
[Zoom Out](/manual/manual-index/toolbar/zoom-out).

## Where to find it

**View → Zoom → Zoom out**, or press <Shortcut client:load keys="cmd+-" />.
