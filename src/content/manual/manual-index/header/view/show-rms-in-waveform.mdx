Toggles the RMS overlay in the waveform display. RMS (root mean square) is
a measure of average level, so with the option on each waveform shows an
inner, lighter band of perceived loudness inside the peak outline. Display
only — the audio itself is untouched.

The setting applies to the whole application, not per project.

## Where to find it

**View → Show RMS in waveform**. The menu item is checked while the option
is on.
