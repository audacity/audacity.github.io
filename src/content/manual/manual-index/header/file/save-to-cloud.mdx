Saves the current project to your cloud library on audio.com rather than to
a file on your computer. You are asked to give the project a name, and it is
then uploaded and kept in sync.

## Where to find it

**File → Save to cloud…**

## Notes

- Once a project is a cloud project, plain
  [Save](/manual/manual-index/header/file/save) syncs it to the cloud too.
- If you close a cloud project while it is still syncing, Audacity asks
  whether to wait or stop the sync.
- Unavailable while recording.
