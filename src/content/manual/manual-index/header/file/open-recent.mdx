A submenu listing the projects you have opened most recently — pick one to
open it again without going through the file dialog. The list updates
automatically as you open and save projects.

## Where to find it

**File → Open recent**.

## Notes

- A **Clear recent files** item at the bottom of the submenu empties the
  list. It removes the entries only — the project files themselves are not
  affected.
- When there are no recent projects, the submenu is greyed out.
