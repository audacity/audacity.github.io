A submenu for exports that are not audio renders: label tracks and MIDI.

## Where to find it

**File → Export other**.

## Export labels

Exports the labels in the project to a text file. See
[Export labels](/manual/manual-index/track-control-panel/label-track-item/additional-options/export-labels)
for details — the same command is also available from a label track's
options menu.

## Export MIDI

**Not yet enabled in the current Audacity 4 alpha.**
