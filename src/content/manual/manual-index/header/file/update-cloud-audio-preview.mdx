Regenerates the audio preview that accompanies a cloud project on audio.com,
so the preview people hear online matches the current state of the project.
The project is saved to the cloud first, then the preview is rebuilt from it.

## Where to find it

**File → Update cloud audio preview**.

## Notes

- Only available for cloud projects — for a project saved on your computer
  the item is greyed out.
- If the project has unsaved changes, Audacity warns that it must be saved
  before updating the preview, with the choice to save and continue or
  cancel.
- Unavailable while the project is empty of audio, and while recording.
