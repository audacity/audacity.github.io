Saves the current project under a new name or in a new place. Unlike
[Save](/manual/manual-index/header/file/save), it always asks where the
project should go — use it to make a separately-saved copy, or to move a
project without touching the original.

## Where to find it

**File → Save as…** There is no default keyboard shortcut.
