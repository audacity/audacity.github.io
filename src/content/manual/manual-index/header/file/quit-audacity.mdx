Exits Audacity. Every open window's project is closed in turn, and any
project with unsaved changes asks whether to save first — choosing **Cancel**
in any of those prompts stops the exit and leaves Audacity running.

## Where to find it

**File → Exit**, or press <Shortcut client:load keys="cmd+q" />.

## Notes

- Unavailable while recording — stop the recording first.
