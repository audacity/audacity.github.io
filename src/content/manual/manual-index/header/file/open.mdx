Opens a project or audio file from disk. The file dialog lists Audacity 4
projects (`.aup4`), Audacity 3 projects (`.aup3`) and every audio and media
format Audacity can import.

## Where to find it

**File → Open…**, or press <Shortcut client:load keys="cmd+o" />.

## Notes

- Choosing an audio or media file rather than a project starts a new project
  with that file imported into it.
- If the current window already has a project open, the file you choose opens
  in a new window. A project that is already open somewhere is simply brought
  to the front rather than opened twice.
- The dialog starts in the folder you last opened a project from.
