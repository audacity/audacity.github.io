Closes the current project without quitting Audacity. If the project has
unsaved changes, you are asked whether to save them first — with the options
to save, close without saving, or cancel and keep the project open.

## Where to find it

**File → Close project**, or press <Shortcut client:load keys="cmd+w" />.

## Notes

- With one window open, closing the project returns you to the home screen.
  With several windows open, the command closes the current window instead.
- Closing a cloud project while it is still syncing asks whether to wait for
  the sync or stop it.
- Unavailable while recording.
