Adds one or more files to the project you already have open — unlike
[Open](/manual/manual-index/header/file/open), which starts a separate
project. The file dialog accepts a wide range of formats: common audio
formats, video files (Audacity imports their audio), and text-based files
such as `.txt`, `.srt` and `.vtt`.

## Where to find it

**File → Import…**, or press <Shortcut client:load keys="cmd+shift+i" />.

## Notes

- Import needs an open project, and is unavailable while recording.
