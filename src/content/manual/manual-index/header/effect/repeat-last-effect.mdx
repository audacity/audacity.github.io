Applies the effect you most recently used to the current selection again,
with the same settings, without reopening the effect's window. Useful when
the same treatment needs to go on several clips or tracks in a row.

## Where to find it

**Effect** menu, or press <Shortcut client:load keys="cmd+r" />.

## Notes

Playback stops before the effect is applied. If you haven't applied an
effect yet in this session, there is nothing to repeat.
