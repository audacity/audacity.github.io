Opens the **Manage plugins** dialog — a table of every plugin Audacity has
found, with a switch to enable or disable each one. Disabled plugins stay
installed but disappear from the menus.

## Where to find it

The first item in each of the **Generate**, **Effect**, **Analyze** and
**Tools** menus. It is the same dialog from all four — one place to manage
every kind of plugin.

## Notes

The dialog has dropdown filters and a search field above the table, so you
can narrow the list by plugin type, category or enabled status, or find a
plugin by name. Which menu a plugin appears in is decided by what it is:
generators land in Generate, processors in Effect, analyzers in Analyze and
tools in Tools.
