Adds a new label track. Label tracks hold text markers rather than audio,
letting you annotate points or ranges in the project — verse boundaries,
retakes, edit notes.

## Where to find it

**Tracks → New label track**.

## Notes

You do not have to create a label track by hand first: adding a label with
[Add label](/manual/manual-index/header/edit/label/add-label) creates one if
the project has none. Labels can be exported as a text file from
**File → Export other → Export labels**.
