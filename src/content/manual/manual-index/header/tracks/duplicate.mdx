Copies each selected track, contents and all, into a new track below it.
The copies are independent — editing one leaves the original untouched.

## Where to find it

**Tracks → Duplicate**.

## Notes

Useful before a destructive edit you might want to back out of: duplicate
the track, work on the copy, and mute or remove whichever version you don't
keep. Nothing happens if no track is selected.
