Adds a new, empty mono track below the existing tracks. A mono track holds a
single channel of audio — the usual choice for a microphone or any other
single-source recording.

## Where to find it

**Tracks → New mono track**, or press <Shortcut client:load keys="cmd+shift+n" />.

## Notes

The new track is empty and ready to record or paste into. To record into it,
select it first, then start recording — see
[Record on current track](/manual/manual-index/header/record/record-on-current-track).
