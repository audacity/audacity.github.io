The pan knob places an audio track in the stereo field. It runs from **100
left** through centre to **100 right**, in steps of 1. A tooltip appears while
you use it, reading `Pan:` followed by the value — for example `50L` or
`50R`. At the centre position the value is shown with no direction letter.

## Using it

- Drag the knob to set a value. Dragging works both vertically and
  horizontally.
- Double-click the knob to return the track to centre.
- With the knob focused, the up and down keys step the value by 1.

## Notes

The knob is hidden while the track is collapsed. Panning is a playback
setting; the audio in the track is not altered.
