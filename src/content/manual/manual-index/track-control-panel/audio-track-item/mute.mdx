**Mute** is a toggle button on an audio track's control panel, next to
[Solo](/manual/manual-index/track-control-panel/audio-track-item/solo). While
it is switched on the track is not heard during playback. Nothing about the
audio itself changes — muting is a playback state, and it can be switched on
and off at any time.

## Notes

A muted track's level meters read nothing, since no signal is leaving the
track.

Mute is stored per track and saved with the project.

When the track is collapsed, mute and solo move up beside the track name so
they remain available.
