**Solo** is a toggle button on an audio track's control panel, next to
[Mute](/manual/manual-index/track-control-panel/audio-track-item/mute). While
any track in the project is soloed, only the soloed tracks are heard on
playback; everything else is held back. Soloing more than one track lets you
listen to that group together.

## Notes

Solo is a playback state and changes nothing about the audio, so it can be
switched on and off freely while you work.

Solo is stored per track and saved with the project.

When the track is collapsed, solo and mute move up beside the track name so
they remain available.
