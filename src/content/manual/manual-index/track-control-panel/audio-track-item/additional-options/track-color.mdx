**Track color** is a submenu of the track menu offering nine colours: Blue,
Violet, Magenta, Red, Orange, Yellow, Green, Turquoise and Cyan. Choosing one
sets the colour the track's clips are drawn in.

The colour currently in use is ticked, so the submenu doubles as a way of
seeing which colour a track has been given.

## Notes

Colour is a display property — it changes nothing about the audio. It is
stored per track and saved with the project, and the change is undoable.
