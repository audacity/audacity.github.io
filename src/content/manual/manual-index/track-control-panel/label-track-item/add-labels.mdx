**Add label** runs across the bottom of a label track's control panel. It adds
a label and immediately puts it into rename mode, so you can type its text
without a second click.

Where the label lands depends on what the project is doing:

- While playing or recording, the label is placed at the current playback or
  recording position.
- Otherwise it takes the selected time range — giving a point label when
  nothing is selected, and a label spanning the range when something is.

## Where to find it

The button on the label track's control panel, or press
<Shortcut client:load keys="cmd+b" />.

## Notes

The button is hidden while the track is collapsed; the shortcut still works.

Labels are edited afterwards in the track itself rather than from the control
panel.
