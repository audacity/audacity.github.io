**Track color** is a submenu of the label track's menu offering the same nine
colours as an audio track: Blue, Violet, Magenta, Red, Orange, Yellow, Green,
Turquoise and Cyan. The colour currently in use is ticked.

## Notes

Colour is purely a display property and changes nothing about the labels
themselves. It is stored per track, saved with the project, and the change is
undoable.

Giving different label tracks different colours is a quick way to tell several
sets of markers apart at a glance.
