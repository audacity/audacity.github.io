Alongside the [timeline](/manual/manual-index/timeline), which shows time as
a ruler, Audacity 4 shows time as numbers you can read and type into. There
are two places to look.

## Playback position

<UIShot
  name="readouts/TimecodeStartEnd"
  alt="The selection start and end readouts"
/>

The [timecode](/manual/manual-index/toolbar/selection#timecode) in the Transport
toolbar shows where the playhead is. Click a digit to edit it and type a
position to move the playhead there. It can be displayed in clock time,
samples, frames, `beats:bars` and several other formats.

## Selection start, end and duration

The Selection toolbar, docked along the bottom of the window, shows the
current selection as three figures: **Selection** start and end, and
**Duration**. All three are editable — type a new start or end to move that
edge of the selection, or type a duration to move the end so the selection
becomes that long.

The start and end pair and the duration each carry their own format, chosen
the same way as the playback timecode, so you can read the selection in clock
time while reading its length in seconds, or the other way round.

The readouts are greyed out when there is nothing selected.

## Notes

- In the `beats:bars` format, the figures follow the project
  [tempo](/manual/manual-index/toolbar/music#tempo) and
  [time signature](/manual/manual-index/toolbar/music#time-signature).
- See [Toolbar](/manual/manual-index/toolbar) for how the toolbars are laid
  out and which controls each workspace shows.
