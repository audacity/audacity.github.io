The **General** page holds the settings that do not belong to any one part
of the application.

## What it covers

- **Language** — the interface language, and updates to the current
  language pack.
- **Number format** — how numbers are displayed.
- **Automatic updates** — whether Audacity checks for new versions.
- **Temporary files** — where working files are written, and how much free
  space is available there.
- **FFmpeg library** — locating the optional FFmpeg library, which adds
  import and export support for more formats.
- **Crash reports and usage information** — whether diagnostic data is
  sent to the Audacity team.
