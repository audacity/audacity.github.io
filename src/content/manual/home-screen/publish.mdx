**Not yet enabled in the current Audacity 4 alpha.**

Publish is intended as a third area of the window alongside Home and
Project, gathering the commands that get finished work out of Audacity. In
the current alpha the tab is not shown and the page behind it is a
placeholder, so there is nothing to describe yet.

Until it arrives, publishing work is done from the File menu and the Hotbar:

- [Export audio](/manual/menu-bar/file#export-audio) — write the
  project out as an audio file.
- [Export other](/manual/menu-bar/file#export-other) — labels and
  MIDI.
- [Share audio](/manual/project-toolbar#share-audio) — upload to
  audio.com.
- [Save to cloud](/manual/menu-bar/file#save-to-cloud) — keep the
  project itself in the cloud.
