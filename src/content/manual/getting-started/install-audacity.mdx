Audacity is free, open source, and runs on Windows, macOS and Linux. This page
takes you from a fresh download to an application you can open. It should take
about five minutes, most of which is the download itself.

## Before you start

You need around 500 MB of free disk space and, for the installer, an account
with permission to install software on the machine. If you're on a managed
work computer you may need whoever administers it to approve the install.

<Callout type="info">
  Audacity does not require an account, a licence key, or an internet connection
  after it's installed.
</Callout>

## Download the installer

<ManualDownloadButton client:load />

It downloads the build for your platform. Every build for every operating
system is on the [download page](/download) if you need a different one.

<Tabs>
  <Tab label="Windows">

Download the `.exe` installer. Both 64-bit and 32-bit builds are listed —
choose 64-bit unless you know the machine is 32-bit.

Once it's downloaded, double-click the file and follow the prompts. You can
accept every default; the installer will suggest a location and create a
Start menu entry.

  </Tab>
  <Tab label="macOS">

Download the `.dmg` disk image, then open it and drag the Audacity icon into
your Applications folder.

The first time you open it, macOS may warn that the application was
downloaded from the internet. Choose **Open** to confirm.

  </Tab>
  <Tab label="Linux">

Audacity is available as an AppImage, and through most distribution package
managers.

The AppImage needs no installation — make it executable and run it. Package
manager versions may lag behind the current release.

  </Tab>
</Tabs>

## Open Audacity for the first time

Launch Audacity the way you'd launch anything else on your system. The first
time it opens — and only the first time — a short setup runs: five pages of
questions about how you intend to work. None of the answers are permanent;
everything here can be changed later from **Preferences** or the toolbar.

### Pick a theme

<UIShot
  name="app/SceneFirstLaunchSetup"
  alt="Setup page one: choosing between the light and dark theme, with accent colour swatches below"
/>

Light or dark, your call — **Follow system theme** hands the choice to your
operating system instead, and **Enable high-contrast** is there if you need
stronger contrast to read the interface comfortably. The row of swatches sets
the accent colour Audacity uses for selections and highlights.

### Choose how clips look

<UIShot
  name="app/SceneFirstLaunchClips"
  alt="Setup page two: choosing between Colorful and Classic clip visualization"
/>

**Colorful** gives each track its own colour, which makes a busy project much
easier to scan. **Classic** keeps every clip in the single style Audacity 3
used.

### Choose a workspace

<UIShot
  name="app/SceneFirstLaunchWorkspace"
  alt="Setup page three: choosing between the Modern and Classic workspace layouts"
/>

A workspace is a toolbar layout. **Modern** is the cleaner default and what
this guide's screenshots use; **Classic** arranges things to match Audacity 3,
which is the gentler landing if you're coming from there. You can switch
whenever you like from the [workspace dropdown](/manual/workspaces) in the
toolbar.

### Connect audio.com — or don't

<UIShot
  name="app/SceneFirstLaunchAudiocom"
  alt="Setup page four: signing in to an audio.com account"
/>

An [audio.com](https://audio.com) account powers saving projects to the cloud
and sharing audio straight from the app. It's genuinely optional — press
**Next** to skip it, and nothing in the rest of this guide needs it.

### Updates and privacy

<UIShot
  name="app/SceneFirstLaunchUpdates"
  alt="Setup page five: app update notifications and crash report settings"
/>

Three things are set here: Audacity notifies you in-app when a new version is
available, sends automatic crash reports to help improve the product, and
generates a random installation ID so usage can be counted — the ID carries
no personal information, and the **Disable UUID** button opts out on the
spot. All three can be changed later under **Preferences → General**, and
the [privacy notice](/legal/privacy-notice) spells out exactly what leaves
your machine.

Finish the last page and Audacity opens for real. That's the install done —
you're ready to
[connect your microphone](/manual/getting-started/connect-your-microphone).

<BestPractices>
  Download from audacityteam.org rather than a third-party mirror — builds
  hosted elsewhere are sometimes bundled with software you didn't ask for. Keep
  the installer file until you've confirmed Audacity opens, in case you need to
  run it again.
</BestPractices>

<Pitfalls>
  Installing over a much older version can carry settings forward that no longer
  apply. If Audacity behaves oddly after an upgrade, resetting preferences is
  usually the fastest fix. On managed machines, an install that appears to
  succeed but leaves no application behind has usually been blocked by policy.
</Pitfalls>
