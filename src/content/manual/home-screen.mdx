Home is the screen Audacity shows when no project is open, and the one the
**Home** tab at the top left returns you to at any time. It is a project
browser: nothing on it edits audio. The **Project** tab beside it switches
back to the editing view, and stays greyed out until a project is open.

<UIShot
  name="app/SceneHomeProjects"
  alt="The Home screen: the sidebar menu on the left, the project tabs and the New & recent grid"
/>

Down the left is a narrow menu, which collapses to icons when the window is
narrow:

- **[Cloud account](/manual/home-screen/cloud-account)**: your audio.com
  account. Only shown when cloud support is enabled.
- **[Project](/manual/home-screen/project)**: the projects browser, which
  is what Home opens on.
