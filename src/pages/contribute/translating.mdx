## Join the project on Transifex

Translation happens on Transifex. Find the Audacity project at
[explore.transifex.com/audacity/audacity](https://explore.transifex.com/audacity/audacity/) and:

1. Click the **Join this project** button on the right side.
2. Select the language you would like to contribute to from the dropdown.
3. Click **Join project** if the language is available to join, or **Request language** if it is not listed yet.

project then appears in your Transifex dashboard and you can start
contributing.

## Translate strings

1. Click **Translate** at the top right.
2. Select **Audacity** from the resource overview to start editing.
3. Select a string and type the corresponding translation in your language.
4. Click **Save translation** and move to the next string.

<Figure
  src={[

The editor has keyboard shortcuts that speed the workflow up, listed under its
overflow menu. The most useful is **Tab**, which saves the current string and
moves straight to the next one.

## Join the translator community

Questions, and notice of upcoming releases that need translation, live in two
places:

- [The translator channel on Discord](https://discord.gg/UvNH4cFjVP)
- [The audacity-translation mailing list](https://sourceforge.net/projects/audacity/lists/audacity-translation)

And that's it. Happy translating!
